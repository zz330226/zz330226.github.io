## Hexo 博客侧边栏搜索框
- 在首页右侧边栏博主简介（card_author）上方添加了搜索框
- 利用 Butterfly 的 `card_top_self` 机制 + `source/_data/widget.yml` 自定义注入
- 搜索数据源：`hexo-generator-search` 生成的 `/search.xml`
- 搜索方式：侧边栏内联展示结果（非弹窗）
- 新建文件：
  - `source/_data/widget.yml` — 搜索框卡片 HTML 定义（top 组）
  - `source/js/sidebar-search.js` — 搜索逻辑（实时搜索、防抖、高亮）
  - `source/css/sidebar-search.css` — 搜索框样式（适配亮暗主题）
- 修改文件：
  - `_config.butterfly.yml` — inject.head 引入 CSS，inject.bottom 引入 JS
- 注意：widget.yml 结构必须是 `top:` + 数组，不能直接写成根级数组
