## 前言

今天（5月27日）一早，雷军在微博宣布了一个重磅消息：**小米 MiMo-V2.5 系列 API 永久降价，最高降幅达 99%**。这是继 DeepSeek 之后，又一家宣布 API 永久降价的大模型厂商。

作为经常折腾各类 AI API 的开发者，这种价格战对我们来说就是实打实的福利。下面来详细看看这次降价的干货。

## 降价核心信息

| 项目 | 详情 |
|------|------|
| 降价对象 | MiMo-V2.5-Pro、MiMo-V2.5（标准版） |
| 降价性质 | **永久性**降价 |
| 最高降幅 | **99%** |
| 生效时间 | 2026 年 5 月 27 日 0:00（全球同步） |
| 计费变化 | 不再区分上下文窗口长度 |

|--------|------------------------|--------------|----------------|------|
| 输入（缓存命中） | **0.025** | 1.40 | 2.80 | 最高 **99%** |

|--------|------------------------|--------------|----------------|------|
| 输入（缓存命中） | **0.020** | 0.56 | 1.12 | 最高 **98%** |

## 两大关键变化

### 1. 不再区分上下文窗口

以前使用长上下文（256k-1M）的价格是短上下文的两倍，现在**全部统一价格**。这对需要处理长文档、长对话的场景来说是巨大利好——等于长窗口用户额外获得了约 50% 的降幅。

### 2. Token Plan 计费优化

同等付费下，Token 用量提升至原来的 **5~8 倍**。而且所有已订阅 Token Plan 且仍在有效期内的用户，Credits 额度会**全量重置**，按新计费规则执行。

## 价格直接对标 DeepSeek

最有意思的是，降价后小米 MiMo-V2.5-Pro 的定价与 DeepSeek-V4-Pro（5月31日调价后）**完全一致**：

| 计费项 | MiMo-V2.5-Pro | DeepSeek-V4-Pro |
|--------|--------------|-----------------|
| 输入（缓存命中） | 0.025 元 | 0.025 元 |
| 输入（未命中） | 3.000 元 | 3.000 元 |
| 输出 | 6 元 | 6 元 |

这意味着小米在高端模型定价上直接对标了 DeepSeek，选择了"跟随定价"策略。对于开发者来说，多了一个同等性价比的选择，总归是好事。
