FastAPI 简介

FastAPI 是现代、高性能的 Python Web 框架，基于 Starlette 和 Pydantic 构建。

核心优势：

  • 性能媲美 NodeJS 和 Go
  • 自动生成 API 文档（Swagger UI）
  • 类型提示，编辑器支持友好
  • 异步支持，高并发场景首选
