Docker 简介

Docker 是容器化技术的代表，将应用及其依赖打包成轻量级容器，实现「一次构建，到处运行」。

核心优势：

  • 环境一致性，告别「在我机器上能跑」
  • 快速部署，秒级启动
  • 资源隔离，安全可靠
  • 版本管理，方便回滚
