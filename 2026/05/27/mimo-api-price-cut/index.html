小米 MiMo-V2.5 API 永久降价 99%，价格直接对标 DeepSeek

发表于2026-05-27|更新于2026-05-27|AI前沿资讯
|浏览量:

前言

今天（5月27日）一早，雷军在微博宣布了一个重磅消息：**小米 MiMo-V2.5 系列 API 永久降价，最高降幅达 99%**。这是继 DeepSeek 之后，又一家宣布 API 永久降价的大模型厂商。

作为经常折腾各类 AI API 的开发者，这种价格战对我们来说就是实打实的福利。下面来详细看看这次降价的干货。

降价核心信息

项目 详情
降价对象 MiMo-V2.5-Pro、MiMo-V2.5（标准版）
降价性质 永久性降价
最高降幅 99%
生效时间 2026 年 5 月 27 日 0:00（全球同步）
计费变化 不再区分上下文窗口长度

两大关键变化

1. 不再区分上下文窗口

以前使用长上下文（256k-1M）的价格是短上下文的两倍，现在全部统一价格。这对需要处理长文档、长对话的场景来说是巨大利好——等于长窗口用户额外获得了约 50% 的降幅。

2. Token Plan 计费优化

同等付费下，Token 用量提升至原来的 5~8 倍。而且所有已订阅 Token Plan 且仍在有效期内的用户，Credits 额度会全量重置，按新计费规则执行。

价格直接对标 DeepSeek

最有意思的是，降价后小米 MiMo-V2.5-Pro 的定价与 DeepSeek-V4-Pro（5月31日调价后）完全一致：

计费项 MiMo-V2.5-Pro DeepSeek-V4-Pro
输入（缓存命中） 0.025 元 0.025 元
输入（未命中） 3.000 元 3.000 元
输出 6 元 6 元

这意味着小米在高端模型定价上直接对标了 DeepSeek，选择了”跟随定价”策略。对于开发者来说，多了一个同等性价比的选择，总归是好事。

新用户体验福利

  • 注册链接：https://platform.xiaomimimo.com?ref=JFAX7G
  • 注册后点控制台左下方入口填入邀请码即可

10 块钱的体验金，按新价格算，MiMo-V2.5 标准版的输出可以跑 500 万 tokens，足够好好体验一番了。

总结

这次小米降价有几个值得关注的信号：

  1. 大模型 API 进入”白菜价”时代 — 99% 的降幅放在一年前简直不敢想象
  2. 长上下文不再溢价 — 统一定价策略让长文档处理成本大幅下降
  3. 对标 DeepSeek — 头部厂商之间的价格战，最终受益的是开发者
  4. 小米持续投入 AI — 雷军表示还要再砸 600 亿，说明这不是短期行为

如果你在找性价比高的大模型 API，MiMo-V2.5 系列现在绝对值得试试。注册链接放上面了，记得填邀请码拿体验金 👆
