什么是装饰器

装饰器（Decorator）是 Python 的高级特性，本质上是一个函数，用于「装饰」其他函数，在不修改原函数代码的情况下增加额外功能。

通俗理解：
就像给手机贴膜，手机本身功能不变，但多了一层「保护」功能。装饰器就是给函数「贴膜」。
